NÉVRA — TIENDA DE MODA FEMENINA
1. Extrae el ZIP.
2. Abre la carpeta nevra_mujer en Visual Studio Code.
3. Abre index.html en el navegador para ver la web.
4. Para probar la bolsa, añade prendas y pulsa Bolsa.
Los productos, precios e imágenes son de demostración.
El checkout NO procesa pagos ni envía pedidos. No introduzcas datos personales o bancarios reales.
Para modificar productos y precios, edita el array 'products' de script.js.
